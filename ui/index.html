Ask a question in plain English, get an answer from a real SQLite database. When the SQL is wrong — a bad table, a bad column — the agent reads the database error and repairs it against the live schema. Every attempt is shown below, fixes included.

HOW IT WORKS

1 · Write

The brain (mock patterns, or a real LLM behind the same interface) writes one SQLite query against the schema it was shown.

2 · Execute

The query runs for real against the seeded shop database — customers, products, orders, 120 days of rows.

3 · Repair

On an error, the agent diffs the error against the live schema: bad table/column names get swapped to their closest real match.

4 · Retry, bounded

Max 2 repairs. If nothing fixes it, the agent fails loudly with the last error — it never silently returns wrong numbers.
